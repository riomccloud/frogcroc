# FrogCroc

Small TUI wizard for sending and receiving files using [Croc](https://github.com/schollz/croc).

## Features
- Simple and easy to use TUI interface
- Send one or more files and folders by dragging them to the shortcut
- Receive files in any directory using an entry in the context menu

## Installation and use
Download the package for your language under [Releases](https://github.com/riomccloud/frogcroc/releases/latest). Extract and run the .bat installer as Administrator.
It'll install the script to `C:\Programs\Croc`, add a shortcut in Desktop and create a context menu entry.

At the moment, FrogCroc supports English (en) and Brazilian Portuguese (pt-BR) languages.
